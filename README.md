# Тэнгэрийн Бөх

Монгол хээр талын сэдэвтэй, нэг дэлгэцтэй (утсанд зориулсан) эргэлтэт тулааны тоглоом. Цэвэр HTML, CSS, JavaScript. Сан, build хэрэгсэл шаардахгүй.

## Баатрууд
Баатар бүр өөр түвшин, чадвар, зэвсэг, хуяг, дуу, дүрслэлтэй. Олдсон эд зүйл бүгд нэг цүнхэнд орох ч зөвхөн эзэн баатартаа өмсөгдөнө.

| Баатар | Онцлог |
|---|---|
| Бөх | Амь их, шидэлтээр дайсныг ухаан алдуулна |
| Харваач | Алсаас харвана, цохилт хүчтэй |
| Морьт цэрэг | Хуяг нэмэлттэй, хийморь хурдан цуглана |
| Бөө | Сүнс дуудаж эдгээнэ, хийморь маш хурдан цуглана |
| Хоньчин залуу | Тэсвэртэй, нохой, хонио дуудна |

Горимууд: газрын зургийн түвшнүүд (3 хүндрэл), өдрийн тулаан, төгсгөлгүй горим (давалгаа бүрт хадгалагдана).

## Ажиллуулах
Файлуудыг татаад `index.html`-ийг хөтөч дээр нээнэ. Хамгийн тохиромжтой нь жижиг сервер ашиглах:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Фонт (Rubik, Noto Serif) Google Fonts-оос ачаалагдана. Интернетгүй үед системийн фонт ашиглана.

## GitHub Pages дээр байршуулах
1. Шинэ repository үүсгээд эдгээр файлыг оруулна.
2. Repository-ийн **Settings → Pages**.
3. **Build and deployment → Source**: `Deploy from a branch`, branch: `main`, folder: `/ (root)`.
4. Хэдэн минутын дараа `https://<таны-нэр>.github.io/<repo>/` хаягаар нээгдэнэ.

## Бүтэц
```
index.html   дэлгэцийн HTML
style.css    загвар
game.js      тоглоомын бүх логик (тулаан, баатрууд, эд хэрэгсэл, хадгалалт)
```

## Хадгалалт
Ахиц хөтчийн `localStorage`-д хадгалагдана. Хөтчийн өгөгдлийг цэвэрлэвэл арилна. Нүүр дэлгэц дэх «Шинээр эхлэх» товч бүгдийг устгана.
